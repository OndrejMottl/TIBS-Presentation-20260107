# Source of Data for Computer Power

The data in `pc_power.csv` contains information about the computational power of personal computers over time. The data has been obtained from:

- <https://en.wikipedia.org/wiki/Instructions_per_second>
- <https://www.hp.com/us-en/shop/tech-takes/specifications-personal-computers-over-time>
- <https://en.wikipedia.org/wiki/List_of_Intel_processors>
- <https://www.spec.org/cpu/>
- <https://en.wikipedia.org/wiki/History_of_personal_computers>
